# 调查日志

记录本次 Palantir AIP 调查的关键步骤与取证方法，便于日后复现或扩展。

## 2026-08-05

### 第一轮：财报归因
- 问题：Palantir 业绩腾飞的原因
- 方法：WebFetch 被阻断（本机网络限制）→ 改 curl；Google 返回 000（被墙）；Baidu/httpbin/GitHub API 可用
- **突破**：SEC EDGAR 可用（需 `User-Agent: research research@example.com`，否则 403）
- 取证：CIK 0001321655，2026-08-03 8-K（accession 000132165526000039），exhibit 99.1 = Q2 2026 财报新闻稿全文
- 结论：Q2 营收 $1.935B (+93%)，美国商业 +149%，全年指引上调至 +82%；叙事 = "sovereign AI"

### 第二轮：AIP 技术架构
- 取证：FY2025 10-K（000132165526000011，pltr-20251231.htm，2.2MB）全文解析
- 产品页（Contentful JSON `"value":` 正则提取）：Foundry AI OS、Sovereign AI、Ontology
- 结论：AIP = LLM 层叠加 Ontology；私有部署是明文能力；Apollo 保障任意环境部署

### 第三轮：Ontology 自动构建
- 盲区：curl 拿不到 docs 站（Next.js SPA）→ **启用 Chrome MCP（use_browser）真实渲染**
- 站点结构测绘：`/docs/sitemap.xml` 枚举全站
- 关键页面逐个取证：
  - `pipeline-builder-aip`（Generate/Use LLM node/Explain/Transform Assist）
  - `self-host-models`（vLLM/Ollama 容器、air-gapped、数据主权）
  - `create-object-type`（向导自动映射、Generate actions、SuperRepo）
  - `overview-semantic-search`（embedding → Ontology 对象）
  - `pipeline-builder-llm`（LLM 节点）
  - `models-in-the-ontology`（模型绑定对象属性）
- **术语纠错**：Welder 查无此名（sitemap + 站内搜索 765 条结果无匹配）→ 从结论中移除
- 新发现：HyperAuto (SDDI) = SAP 集成工具；Foundry AI OS = AIP 演进品牌

### 环境与工具备忘
- curl 可访问：SEC.gov（带 UA）、Baidu、httpbin、GitHub API、palantir.com 产品页（部分）
- curl 不可用：Google（000）、Reuters（000）、DuckDuckGo（验证码）、Bing（Access Denied）、docs 站正文（SPA）
- Chrome MCP（use_browser）：可用，能渲染 JS 页；需 `navigate → extract` 流程；注意 `extract` 返回全文含侧边栏，用 eval 定位正文
- Windows 编码坑：python 打印非 ASCII 报 GBK 错 → 写 UTF-8 文件再 Read，或设 `PYTHONIOENCODING=utf-8`
- Git Bash 的 `/tmp` 与 Windows python 路径不一致 → 用显式 Windows 路径（`C:/Users/meta/AppData/Local/Temp/...`）
